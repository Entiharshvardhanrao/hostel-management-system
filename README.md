# 🏨 Hostel Management System

A full-stack Hostel Management System built using Django and Bootstrap to streamline hostel operations through a centralized platform.

The system provides separate dashboards for administrators and students, enabling efficient management of hostel activities such as student records, complaints, leave requests, food menus, and payments.

---

## 🚀 Features

### Admin Panel
- Student Management
- Leave Request Management
- Complaint Management
- Food Menu Management
- Payment Management
- Dashboard Analytics
- Secure Admin Authentication

### Student Portal
- Student Login
- View Personal Information
- Raise Complaints
- Apply for Leave
- View Leave Status
- Check Weekly Food Menu
- Track Payment Records

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/hostel-management-system.git
```

### Navigate to Project

```bash
cd hostel-management-system
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Migrations

```bash
python manage.py migrate
```

### Create Admin User

```bash
python manage.py createsuperuser
```

### Run Server

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000
```
